# Transform

[Вернуться к главной странице](README.md)

Инструменты для преобразования итерируемых сущностей в другие структуры данных.

---

### Partition
Разделяет коллекцию на два списка на основе предиката.

Возвращает массив из двух списков: `[истинные значения, ложные значения]`. Оба выходных массива — списки с переиндексацией (с нулевыми индексами); ключи исходной коллекции отбрасываются. Значение, возвращаемое предикатом, приводится к булевому типу через `(bool)`.

```Transform::partition(iterable $data, callable $predicate): array```

```php
use IterTools\Transform;

$numbers = [1, 2, 3, 4, 5, 6];

[$evens, $odds] = Transform::partition($numbers, fn (int $n): bool => $n % 2 === 0);
// $evens: [2, 4, 6]
// $odds:  [1, 3, 5]
```

### Tee
Создает несколько одинаковых независимых итераторов из данной коллекции.

```Transform::tee(iterable $iterable, int $count): array```

```php
use IterTools\Transform;
$daysOfWeek = ['Mon', 'Tues', 'Wed', 'Thurs', 'Fri', 'Sat', 'Sun'];
$count = 3;
[$week1, $week2, $week3] = Transform::tee($daysOfWeek, $count);
// Каждый $week — итератор, содержащий ['Mon', 'Tues', 'Wed', 'Thurs', 'Fri', 'Sat', 'Sun']
```

Копию можно перемотать в начало, пока она не продвинулась. После этого `rewind()` выбрасывает `\LogicException`, поэтому приём «продвинуть одну копию и объединить копии через `zip`» выбрасывает исключение, когда `zip` их перематывает. Для соседних пар используйте [`Single::pairwise()`](single-iteration.md#pairwise).

Если источник выбрасывает исключение, каждая копия всё равно выдаёт элементы до сбоя, а затем, дойдя до него, выбрасывает тот же объект исключения. После сбоя источник больше не читается, поэтому копия никогда не завершается досрочно без исключения.

### To Array
Преобразует итерируемую коллекцию в массив.

```Transform::toArray(iterable $iterable): array```

```php
use IterTools\Transform;
$iterator = new \ArrayIterator([1, 2, 3, 4, 5]);
$array = Transform::toArray($iterator);
```

### To Associative Array
Преобразует итерируемую коллекцию в ассоциативный массив.

```Transform::toAssociativeArray(iterable $iterable, ?callable $keyFunc = null, ?callable $valueFunc = null): array```

```php
use IterTools\Transform;
$messages = ['message 1', 'message 2', 'message 3'];
$keyFunc   = fn ($msg) => \md5($msg);
$valueFunc = fn ($msg) => strtoupper($msg);
$associativeArray = Transform::toAssociativeArray($messages, $keyFunc, $valueFunc);
// [
//     '1db65a6a0a818fd39655b95e33ada11d' => 'MESSAGE 1',
//     '83b2330607fe8f817ce6d24249dea373' => 'MESSAGE 2',
//     '037805d3ad7b10c5b8425427b516b5ce' => 'MESSAGE 3',
// ]
```

Ключи подчиняются семантике массивов PHP: повторяющийся ключ сохраняет позицию первого вхождения и последнее значение, а десятичная целочисленная строка вроде `'1'` хранится как int `1`. Ключ, не являющийся int или string (float, `null`, `bool`, массив или объект), приводит к `\InvalidArgumentException`, а не преобразуется и не теряется.

### To Iterator
Преобразует итерируемую коллекцию в итератор.

`IteratorAggregate`, например `Stream`, даёт итератор, который возвращает его `getIterator()`, проходя вложенные агрегаты до первого итератора, а не обёртку вокруг него. Поэтому агрегат над итератором или генератором даёт тот же самый объект, а агрегат, возвращающий новый итератор при каждом вызове, например `ArrayObject` или результат `memoize()`, каждый раз даёт новый. Выбрасывает `\LogicException`, если `getIterator()` возвращает значение, не реализующее `Traversable`, или если агрегаты образуют цикл, например агрегат, чей `getIterator()` возвращает сам себя.

```Transform::toIterator(iterable $iterable): \Iterator```
```php
use IterTools\Transform;
$array = [1, 2, 3, 4, 5];
$iterator = Transform::toIterator($array);
```
### Memoize

`Transform::memoize($iterable)` лениво кэширует пары ключ/значение, позволяя текущим и будущим потребителям начать с начала и чередоваться при одном обходе источника. Если источник бросает исключение, успешный префикс остаётся доступен, а каждый потребитель на границе получает тот же объект исключения. Повторный (реентрантный) вызов продвижения источника не поддерживается. Клон результата — ещё один дескриптор той же мемоизированной последовательности: он разделяет с оригиналом источник и кэш.

Кэш растёт вместе с максимально потреблённым префиксом и не освобождается. Массивы и повторно итерируемые агрегаты также оборачиваются. Используйте `tee(n)` для заранее известного числа ветвей с возможным освобождением буфера, а `memoize()` — для неизвестного числа будущих обходов. Кэширование бесконечного источника может потребовать неограниченную память.
